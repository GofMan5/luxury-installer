# Code of Conduct

## Our standard

We want technical discussion to be direct, evidence-based, and welcoming. Contributors and maintainers are expected to:

- discuss code and behavior rather than attacking people;
- give reproducible evidence for security, correctness, performance, and compatibility claims;
- accept disagreement without harassment, threats, discrimination, or unwanted personal attention;
- protect private information and report vulnerabilities through the private channel;
- make room for contributors with different experience levels, languages, and backgrounds.

Unacceptable behavior includes harassment, discriminatory language, sexualized attention, doxxing, deliberate intimidation, sustained disruption, and publishing another person's private information without permission.

## Scope

This standard applies in repository issues, pull requests, discussions, reviews, release channels, and public spaces where someone represents the project.

## Enforcement

Maintainers may edit or remove content, lock threads, reject contributions, or temporarily or permanently restrict participation when behavior violates this standard. Enforcement should be proportional, documented privately where practical, and focused on protecting the community.

Report urgent conduct concerns privately to the repository owner through GitHub. Do not expose sensitive details in a public issue. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

This policy is inspired by the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
