# Support

Luxury Installer is a development preview. There are no production binaries or compatibility guarantees yet.

## Questions and setup help

Use [GitHub Discussions](https://github.com/GofMan5/luxury-installer/discussions) for build questions, package-authoring help, and design discussion. Include your OS, architecture, Rust/Node/pnpm versions, the command you ran, and the smallest redacted error output that explains the problem.

## Reproducible bugs

Open a [bug report](https://github.com/GofMan5/luxury-installer/issues/new?template=bug_report.yml). Do not attach private keys, certificates, access tokens, personal paths, or proprietary payloads. A minimal synthetic `.luxpkg` project is preferred.

## Security vulnerabilities

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## What maintainers cannot promise

- support for unsigned third-party production deployment;
- signing, notarization, or certificate-provider setup on your behalf;
- recovery of files outside Luxury Installer ownership receipts;
- release support for platforms whose native evidence is still listed as blocked.
